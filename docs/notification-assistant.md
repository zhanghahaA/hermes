# 通知助手开发版（0.15.0-dev.2）

本文的 0.15.0-dev.2 是历史开发代号。已有通知助手整理到 [0.12.0](0.12.md)；[0.13](0.13.md) 在此基础上新增按连接独立档案，并接入本机运行中心。扩展顺延 0.14、浏览器自动操作顺延 0.15；长期记忆尚未开发。

## 怎么用

1. 在「设置 → 通知助手 · 开发版」选择允许读取的应用。
2. 点「固定会话」，绑定当前连接和 Bot；可以新建专用的「通知助手」会话，也可以选择现有会话。
3. 打开助手开关，阅读并确认数据用途；在「系统通知使用权」里手动授权 Hermes。
4. 新通知到达后，可以先查看手机上的过滤结果，再点「立即总结 / 重试」，或等待系统定时处理。
5. 摘要显示在此页面和固定的 Hermes 会话里；App 有通知权限时会提示摘要已完成。

默认每 30 分钟处理一次，可以改为 15 或 60 分钟。Android 的周期任务不是精确定时，锁屏、省电、vivo 的后台管理都可能延迟。需要在手机上验证授权、后台运行、重启恢复和通知到达效果。强制停止 App 后，系统可能不再运行任务，需要重新打开 App。

关闭助手后不再采集或启动下一批发送。已经提交给 Hermes 的任务可能继续完成，关闭手机开关不会撤回服务器任务。

## 记录和发送

- 默认关闭，白名单为空。只采集开启后到达的新通知，不回读系统里已有的通知。
- 忽略 Hermes 自己、持续通知、通知组汇总、播放和后台服务等噪声。
- 银行、支付类应用以及验证码、交易提醒等敏感内容按规则过滤；长数字和已知凭据格式会隐藏。规则可能漏掉其它形式的敏感内容，应谨慎选择应用。
- 可以设置不读取的关键词。修改白名单不会自动删除已存记录；冻结批次涉及的应用需先完成该批次，或暂停并清除本地记录后再移除。
- 通知与摘要在手机私有目录通过 Android Keystore 加密保存，不进入通用诊断导出或系统备份。最多保留 500 条，下次采集或处理时清理超过 7 天的记录。
- 同一通知的重复更新去重；尚未冻结的旧版本由更新替换。发送中到达的新版本留在下一批。
- 每批最多 30 条，批次 ID、固定目标和正文先落盘，再用 notifications-<批次 ID> 作为幂等键提交。接收到 run ID 后立刻保存；重启或断网后查询同一任务，不另建重复任务。
- 固定绑定当前连接、Bot、会话，发送使用独立客户端和 SSH 隧道。0.13 按连接独立保存档案，切换连接时取消手机端旧等待、隔离队列、恢复新档案，新连接默认关闭；切换 Bot 不更改固定 Bot 目标。已提交的服务器任务可能继续运行，不能靠切换撤回。SSH 必须先验证并保存主机指纹；不会在后台接受新指纹或替用户开通 Bot。
- 接口采用现有 /api/sessions、/v1/runs 和任务状态接口，不修改服务器配置。摘要由用户的 Hermes 及其所配置的模型处理。
- 通过独立 instructions 要求把通知 JSON 当作不可信资料，仅输出「需要处理 / 值得留意 / 可以忽略」，不执行通知指令、不使用工具、不写记忆。**这是模型指令，不是服务端工具权限隔离**；App 不自动批准任何审批。严格的工具禁用需要 Hermes 服务端提供并实施相应权限。
- 本地清除会删除待发批次、记录和摘要；已经发送的内容需在 Hermes 的固定会话里另行删除。

## 验证范围

桌面测试覆盖过滤、脱敏、去重、更新替换、队列大小、保留期限、冻结批次、断网与进程重建恢复、幂等键、并发发送和固定 Bot 的真实 HTTP 请求；界面测试覆盖开关确认和应用选择。

Android 自检 NotificationStorageTest 验证真实 Keystore 加密文件的读写，需设备才能执行。桌面版的授权和应用列表只是可控替身，不能证明 Android 授权、NotificationListenerService、JobScheduler 或 vivo 后台行为已经可用。

本轮结果：标准套件报告 190 项、0 失败，实际执行 174 项通过（其中 15 项为本功能新增测试）；另 16 项 RealHermesIT / OpenSshIT 缺少环境配置而没有实际执行。新增真实本机 SSH 测试验证独立隧道、保存的主机指纹和绑定的 Bot 密钥。浅色 / 深色界面已渲染并检查中文与布局。App 与 Android 自检 APK 均构建成功；adb 无设备，Android 存储自检与手机通知流程未执行。

调试签名可通过 Gradle 属性 hermesDebugKeystore 指定文件，不把签名文件放入仓库。本轮 env.sh 已指向保留的签名文件；证书 SHA-256 与此前 0.11.6 的 d985fcaf…db1dc7 一致。versionCode 从 32 增至 33，可供同证书旧版覆盖升级。

## dev.2 页面动画

通知助手现在是全局页面栈中的独立路由。点击设置入口后，与聊天、连接编辑等页面共用进入动画；返回按钮和应用内右滑共用退出、跟手、取消动画。返回后保留设置页选中状态和滚动位置。通知页不再单独消费系统返回事件，交给全局宿主处理。

桌面回归检查从真实设置入口进入时和点击返回时的动画中间进度，以及右滑取消、右滑提交和返回设置页状态。额外渲染实际进入 / 退出动画的中间帧，没有手动伪造位移。Android 系统预测性返回仍需真机验证。

本次 dev.2 验证：标准套件报告 192 项、0 失败，实际执行 176 项通过；另 16 项真实 Hermes / OpenSSH IT 未执行。新增 2 项导航回归通过，浅 / 深色界面和真实动画的进入 / 退出中间帧已检查。Android 调试 APK 构建成功；签名与 dev.1 一致，versionCode 34，可覆盖 dev.1。无 Android 设备，系统预测性返回未做真机验证。
