# 0.16 开发版

基于 0.15.0-dev.2，版本 `0.16.0-dev`，Android versionCode 35。继承通知助手及其全局进入、返回动画。

## 使用

- 设置 → 聊天 → **逐字显示回复**：已经出现的公开正文保留，工具等待时不再被三个点替换；后续内容另起段落继续显示。开启“显示正在输入”时，三个点放在正文下面。
- 设置 → 聊天 → **思考与工作过程**：默认关闭。打开后，回复使用宽版正文布局，自动实时显示；上方展开服务器发来的思考、工具预览及完成/失败状态。可随时收起，正文继续显示。关闭此开关不会关闭独立的逐字回复开关。
- 底部 **Dock**：横向拖动时，选中背景和图标预览跟随手指；松手吸附到最近标签并切换页面。经过中间标签时不反复加载页面；手势被其它组件接管则回到原标签。点选仍可用。

## 接口与限制

- 已核对 2026-10-23 上游 `api_server.py` 和 `api_server_runs.py`。支持 `message.delta`、`message.interim` 的 `already_streamed` 去重；工具生命周期只分段，不擦除公开正文。`seq` 仍用于断线重播去重。任务结束以服务器 `output` 对齐最后一段，之前的公开段落单独保留。
- 思考来自 `reasoning.available` / `reasoning.delta`；兼容将 `_thinking` 放在 `tool.progress` 的版本。工具以 `tool_call_id` 配对，无 id 时匹配最近未结束的同名工具。未知事件忽略。
- 有的 Hermes 版本或执行路径不发送思考；只能展示实际收到的内容，不补造。此开关不改变模型参数或服务器配置，不会将过程自动发回模型，也不支持引用过程内容。
- 每轮过程最多最近 100 个步骤，每步最多 8,000 字符。过程与阶段性公开旁白只存在当前连接的内存中，刷新正式记录不会擦掉；切换连接/Bot 或重启后不能保证恢复。未完成任务仍按原逻辑订阅服务器可重播的事件。关闭过程开关立即清除已收集的思考/工具步骤，关闭期间不收集。
- Dock 使用现有 Backdrop 玻璃能力，实际折射依赖系统支持；低版本保留半透明背景、跟手和弹簧动画。不是 iOS 的系统组件。
- 开发包沿用 0.15.0-dev.2 的调试签名；仅在签名相同且版本号更低时可直接覆盖安装，不建议卸载以免丢失本地数据。

## 验证

自动测试覆盖连续 100 句、逐字分片、工具等待、重复 interim、断线续传、停止后正文保留、最终正文对齐、默认不收集思考、开关即时生效与清理、过程折叠不影响回复、正文与三个点同时出现，以及真实主页面上的 Dock 跟手、松手切换、手势接管取消和点选。

完整套件报告 202 项、0 失败：186 项实际执行通过，另外 16 项真实 Hermes/OpenSSH 集成测试因环境未配置直接返回，不能算作跑通。Android `assembleDebug` 构建成功；聊天、过程、完成态、Dock 和设置的深浅色截图已渲染检查。全量测试中发现旧归档测试直接断言异步派生 StateFlow，已改为等待实际状态再断言，生产归档逻辑未更改。

没有连接 adb 设备，vivo 手势手感、系统后台和真机折射效果未验证。桌面取消手势测试由父组件接管手势触发，不能代替 Android 系统取消/预测性返回验证。
