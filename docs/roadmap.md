## 产品原则

- **基础免费开源，可选服务收费。** 基础聊天、连接、服务控制与隐私管理保持基础能力；订阅对应实际持续提供的任务、同步或维护。一键部署可以提供按次资格或自愿广告奖励额度。开源客户端可以被依法修改，收入建立在实际服务价值上。
- **每个扩展默认关闭。** 安装、改配置、开启手机能力前说明用途、变更与数据去向，由用户点击确认。
- **授权按具体连接保存。** 手机、家里电脑和每台云服务器分别管理；Android 系统权限不是所有服务器的转发授权。
- **明确数据去向。** 本机 Hermes 调用云端模型时仍会发送相关内容。通知、短信、聊天与密钥不用于广告；仅向明确授权的目标发送必要内容。
- **目标是普通用户不用编写命令。** 安装和敏感授权仍需本人确认；首次 Termux 外部执行设置需要实测，不能把“复制命令粘贴到终端”宣传为已全程按钮操作。
- **如实报告验证。** 模拟测试不替代设备安装、授权、后台与浏览器验证，上游已知不可用的安装方案不能标记为跑通。

## 0.13：本机运行与服务中心

### 外部运行组件，保留合并接口

现阶段采用 Hermes App、标准 Termux、独立 Termux:X11。App 统一操作，Termux 在后台运行本机 Hermes、Python 服务、反向代理、Chromium；浏览器画面在 X11 中打开。远程聊天不要求启动本机 Hermes，使用手机服务或浏览器时按需启用环境。

业务面向可替换的 LocalRuntimeBackend；固定路径、安装源、命令传输与外部窗口放在外部后端，Android Intent 桥与业务分离。将来可实现内置后端，但本轮不承诺已解决单 APK 的包名路径、打包和 Android 执行限制。保留各第三方许可和应有的源码义务，不擅自确定主项目许可证。

草稿位于独立工作区 /workspace/hermes-runtime-0.13，分支 codex/local-runtime。尚未接入界面、完成 Android 桥或验证，不能当作已交付功能。分层与迁移边界见 [运行环境接口约定](runtime-backend-contract.md)。

### 环境、安装与连接

- 检查 Termux 版本、初始化、arm64、空间和执行权限，缺少时引导安装授权。
- 使用经验证的官方 Termux 签名软件源，核对公钥指纹；不用桌面 install.sh 或 glibc 包冒充 Termux 原生包。stable／canary 都须验证。
- 此前上游仍标注 Termux 包正在修复；实施时重新核对并在 arm64 真机跑通，失败时明确阶段，不伪造成功。
- App 管理的配置独立存放，保留已有环境；自动生成本机凭据，接口默认仅监听本机。模型和密钥通过界面配置，不要求编辑文件。
- 实际 API 检查通过后创建「这台手机」连接。后续自动检查、按需启动与恢复，不重复安装；切换远程服务器不擅自卸载本地服务。
- 提供启停、重启、日志、升级和保留数据卸载。vivo、电池优化和 Android 子进程限制需实测，不承诺永久保活。

### Python 与反向代理

服务包描述标识、入口、依赖、配置与目录／网络范围。统一管理状态、启停、日志、更新和移除，验证重复点击与失败恢复。
首批验证一个 Python 程序和一个本机反向代理。带原生依赖的程序需支持 Android／arm64，不承诺任意电脑程序直接运行。
默认只监听本机；局域网／公网需明确设置。虚拟环境不是强安全沙箱，同一 Termux 用户下服务可能共享数据访问能力。软件卸载与用户数据删除分开确认。

### 每个连接独立档案

沿用已有通知采集实现，迁移配置和发送边界。按稳定 connectionId 保存能力开关、白名单、过滤、手动查询／自动转发、后台使用和同步范围。新连接默认关闭敏感能力，复制连接不自动复制授权。

切换连接时停止旧目标的新转发，取消失效请求，隔离队列与重试，再加载新档案。明确说明：已经提交给远程 Hermes 的任务不会仅因手机开关关闭而撤回。
0.12 仍按通知助手固定目标发送，不能提前宣传为已实现这套切换隔离。

### X11 + Chromium 基础部署

保留独立 Termux:X11 和 Chromium，先验证安装、显示、输入、网页访问、登录资料保留及重启。不以 VNC 替代 X11，也不把 Chromium 当成 Google Chrome 原版。
这一步仅部署与打开浏览器，不等同于 Hermes 自动操作已完成。

## 0.14：可选扩展

- 扩展页面：用途、风险、安装／开关／卸载、状态与最近活动。
- Home Assistant：评估官方插件；经用户确认配置地址和令牌。开门锁等敏感操作须审批，用户设备需实际验证。
- Android 11+ ADB 无线调试：引导配对、按范围授权操作、随时断开；重启和换网后的恢复需真机确认，不承诺任意 App 可截屏。

## 0.15：Hermes 驱动本机浏览器

基于 0.13 的 Chromium，接入受控 CDP／Hermes 浏览器能力，提供查看、接管与交还。控制接口不暴露公网，用户资料按选择保留。连接与操作实际跑通后才标记支持。

## 后续：订阅、同步、广告与记忆

- 订阅先定义持续任务、同步、维护及额度，到期保留已有数据和导出能力。
- 用户提及的“墨水瓶”外部服务身份和 API 尚未确认，仅预留适配方向。同步须有离线重试与冲突处理，不承诺手机后台任何时刻实时到达。
- 部署额度可来自订阅、单次购买或自愿广告奖励。完整部署覆盖必要重试，正常启停不重复扣次；订单／奖励回调须真实服务端验证和幂等记账，没有后端时不将演示开关当成已接通。
- 广告平台尚未选定，部分平台须审核；若仍拒绝广告平台审核，另考虑赞助模式。SDK 许可和数据行为需兼容项目的实际许可证与隐私范围。
- 广告不可用不锁住基础聊天、隐私管理、导出和安全修复；付费资格不自动授予手机数据权限。
- 长期记忆基于 Hermes 的记忆能力，用户可审阅、编辑和删除；手机数据参与偏好整理前另行授权。

vivo 原子岛／实况通知继续暂缓。签名、系统预测性返回和其它遗留问题仍按 [交接说明](../HANDOFF.md) 处理。
