# 0.12.0 候选版本

## 版本安排

用户决定重新按交付顺序编号：此前 0.15／0.16-dev 已开发的功能统一整理为 0.12，本机部署计划顺延至 0.13。当前版本为 **0.12.0 / Android versionCode 36**，基于 dev 分支的 a6dbe47。

显示名称从 0.16-dev 改为 0.12 不表示功能或安装版本回退：此前 0.16.0-dev 的 versionCode 是 35，新包增加到 36。覆盖升级还必须使用同一签名；不要通过卸载丢弃本地连接、密钥和通知记录。

本轮只调整版本、开发计划和说明，保留 dev 的生产功能代码。历史开发记录、提交和安装包不改名，不重新解释旧包的版本与测试结果。候选安装包完成构建和验证不等于已发布 GitHub Release。

## 保留的功能

- 通知助手：授权引导、应用白名单、过滤脱敏、本地加密记录、固定连接／Bot／会话、周期批量摘要和到达提醒。入口保持「设置 → 通知助手 · 开发版」，默认关闭；详见 [使用与限制](notification-assistant.md)。
- 持续流式回复：工具等待时保留已出现的公开正文，正文与三个点可以同时显示。
- 思考与工作过程：默认关闭，展示服务器实际返回的思考和工具事件；可展开收起，关闭时清理过程，过程不作为正式聊天正文缓存或引用。
- Dock：拖动跟手、松手吸附切页、点选和玻璃动画。
- 既有聊天、SSH、连接、项目、Bot、群聊、附件、定时任务和管理能力。

当前源码中能确认的是通知助手，没有独立的短信收件箱读取实现；系统短信应用发出的通知可能在用户选择后由通知监听处理，不能据此宣传为已实现读取短信数据库。本轮不新增或改写这些能力。

## 本版不包含的下一阶段功能

Termux 一键部署、本机 Hermes 启停、Python 小服务、反向代理、按连接独立隐私档案及 X11／Chromium 基础部署归入 0.13。普通订阅、外部服务同步和广告奖励未接入，不展示为已可用能力。

0.13 采用独立 Termux 与独立 Termux:X11，由 Hermes App 统一操作。运行环境通过可替换的后端接口接入，为以后合并成单 App 留入口；当前未完成的草稿放在独立工作区，不能混进 0.12 安装包。

通知助手当前仍使用固定目标配置：切换界面连接不会改变已经绑定的通知发送目标。用户提出的“每个连接独立档案、切换即隔离”是 0.13 的迁移要求，本次版本整理没有将其实现，也不能将当前行为描述为已按新方案隔离。
