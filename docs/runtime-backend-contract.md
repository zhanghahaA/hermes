# 0.13 运行环境接口约定

状态：后续实现约定，0.12 不包含本机运行功能。当前未接入、未验证的实现草稿在独立工作区 `/workspace/hermes-runtime-0.13`，分支 `codex/local-runtime`。

用户目前选择外部 Termux + 独立 Termux:X11，并希望以后能够合并。为此将安装、执行和显示行为放在可替换后端，不把外部应用的路径和 Intent 散落到聊天或设置界面。

## 分层

| 层 | 负责 | 不能依赖 |
|---|---|---|
| 页面／业务控制器 | 展示状态、用户确认、步骤串行化、重试、错误反馈 | Termux 包名、shell 字符串、X11 Activity |
| LocalRuntimeBackend | 环境检测、安装、配置、服务启停、日志、浏览器操作 | 具体页面和导航 |
| 外部 Termux 后端 | 官方软件源、固定目录、Termux 命令及结果解析 | 订阅／广告授予手机权限 |
| TermuxTransport | Android 执行命令权限、Intent、关联回调、外部窗口启动 | 模型配置和服务业务策略 |
| LocalConnectionAccess | 安全保存本机凭据、检查 API、切换本机连接 | 外部应用的安装方式 |

后续内置后端实现同一业务契约；不需要保留 TermuxTransport，也不将其外部授权步骤当作内置后端的必要步骤。

## 结构化请求与结果

- 请求表达明确动作：检查、准备依赖、安装／升级 Hermes、配置、启停、服务导入、代理配置、浏览器操作。
- Python 服务和代理使用稳定标识；启动入口、依赖、端口、数据目录必须校验。禁止把用户输入直接拼接进 shell。
- 后端返回运行快照、已脱敏的可展示输出，凭据通过专用字段交给连接存储；不将凭据放入普通状态、异常字符串、诊断或截图数据。
- 请求／结果的默认字符串表示也隐藏敏感正文。操作失败不回显输入的模型 Key 或用户程序。
- 异步结果需关联到唯一操作；旧回调、重复回调、超时、离开页面、进程重建与重复点击须有明确处理。
- 只管理确认为自己启动的进程，校验进程归属；不能按宽泛进程名终止用户其它服务。

## 替换后端时保留的内容

保留服务稳定 ID、连接档案和用户选择；后端变更不默认扩大权限，不将远程目标的权限继承给本机。运行数据目录、浏览器资料和本机凭据的迁移需有显式流程与检查，不能因为两个后端方法名相同就视为数据已自动兼容。

客户端保持能力探测：外部应用未安装、没有执行授权、不支持 arm64、上游安装包不可用，均属于明确状态。不要用成功占位或不执行的桌面替身冒充真机可用。

这份约定为后续合并留接口，不等于已经解决单 APK 下原生程序打包、软件包路径、Android 执行限制、X11 输入渲染和第三方许可。所有这些仍需在目标设备验证。
