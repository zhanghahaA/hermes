# 让手机连上你的 Hermes

直连、HTTPS、本机 Termux 通过 Hermes 自带的 API Server 通信，每台要连接的 Hermes 都按下面做一次。
**SSH 连接（0.14 起）不用 API Server**：手机经 SSH 连到那台电脑上正在运行的 Hermes gateway（和电脑版是同一个服务），
只要 gateway 在运行、手机的公钥加进了 SSH 授权就行，跳到下面的「SSH」一节。

**0.13.1 开始优先使用 App 中的配置向导：**填地址和账号，点「生成并复制配置命令」，在对应机器终端粘贴执行后，回手机点「检查并连接」。API Key 与手机公钥不需要自己编写；已有有效密钥和端口会保留。详细步骤与适用范围见 [简化配置指南](easy-setup.md)。下面保留手动配置方法供高级用户排查。

## 1. 开启 API Server

编辑 Hermes 所在机器上的 `~/.hermes/.env`，加入：

```bash
API_SERVER_ENABLED=true
# 至少 16 位的随机密钥，可以用：openssl rand -hex 32
API_SERVER_KEY=这里换成你生成的密钥
```

然后重启 gateway：`hermes gateway`（或你平时的启动方式）。
看到 `API server listening on http://127.0.0.1:8642` 就成功了。

> 新版 Hermes 要求密钥至少 16 位，太短或是示例值会拒绝启动。

## 2. 让手机能访问到

API Server 默认只监听本机（`127.0.0.1`）的 8642 端口，手机访问不到。端口可以用 `.env` 里的 `API_SERVER_PORT=<端口>` 改。按你的用法选一种：

| 用法 | 怎么设置 | App 里选 |
|---|---|---|
| **Tailscale / ZeroTier**（推荐） | `.env` 加 `API_SERVER_HOST=<这台机器的 Tailscale IP>`，例如 `100.101.22.8` | 直连，地址填这个 IP，端口 8642 |
| **家里局域网** | `API_SERVER_HOST=<局域网 IP>`，例如 `192.168.1.20` | 直连 |
| **反向代理 / Tailscale Serve** | 保持监听 `127.0.0.1`，由代理对外提供 HTTPS | HTTPS，填完整网址 |
| **SSH** | 不用开 API Server，gateway 在运行就行 | SSH（见下文） |
| **手机本机 Termux** | 保持默认 | 本机 Termux |

不建议用 `0.0.0.0` 把它暴露到公网：API Server 能在这台机器上执行命令，只靠一个密钥保护。

## 3. 在 App 里添加连接

设置 → 添加连接 → 选方式 → 填地址和 API Key → 点「测试连接」。
测试会逐项检查，失败时会告诉你卡在哪一步：

| 卡在哪一步 | 一般是什么原因 |
|---|---|
| 网络可达 | 地址或端口不对；Tailscale 没连上；`API_SERVER_HOST` 还是 `127.0.0.1` |
| 识别 Hermes | 这个端口上跑的不是 Hermes；或者 Hermes 太旧，还没有 API Server |
| 识别 Hermes（提示 hermes serve） | 端口被 `hermes serve` / `hermes dashboard`（桌面版、网页版的后端，默认 9119）占了。App 要的是 `hermes gateway` 里的 API Server，两者不是一个东西 |
| API Key 鉴权 | Key 填错了，或者和 `.env` 里的 `API_SERVER_KEY` 不一致 |
| 能力探测 | Hermes 版本太旧（早于 2026.6），没有会话接口，建议升级 |

## SSH

适合：家里的电脑/NAS 开着 SSH。0.14 起手机经 SSH 直接连那台电脑上的 **Hermes gateway**（`hermes gateway` 启动的那个服务，电脑版、TUI 连的也是它），
**不需要开 API Server，也不需要 API Key**；电脑上建的对话在手机上能直接接着聊。

1. 设置 → 添加连接 → SSH，填 SSH 主机（Tailscale IP 也行）、用户名（端口在高级设置里，默认 22）。
2. 点「生成并复制配置命令」，在那台电脑上以这个用户打开终端，粘贴执行。它只做两件事：
   把手机的公钥加进 `~/.ssh/authorized_keys`，再看一眼 Hermes gateway 是否在运行。**不改 Hermes 的配置，不重启服务。**
   - 也可以在高级设置里「导入文件」/「粘贴」你已有的私钥（OpenSSH、PEM、PuTTY 格式都行；暂不支持带口令的私钥，可用 `ssh-keygen -p` 去掉口令），或改用密码登录。
   私钥只加密保存在手机上（Android Keystore），不会发给任何人。
3. 回到手机点「检查并连接」。第一次连接会记住服务器的主机指纹（执行过配置命令的话，App 会核对就是那台机器），
   可以在服务器上用 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 对一下；**以后指纹变了会拒绝连接**（防止有人冒充你的服务器）。重装过服务器的话，在连接设置里点「重置」。

Hermes gateway 要一直开着：在电脑上运行 `hermes gateway`，或者 `hermes gateway install` 装成开机自启的服务。
断网、换网络、服务器重启后，App 会在下一次操作时自动重新登录、重新连上 gateway，断线期间回完的消息会补上。

| 检查连接卡在哪一步 | 一般是什么原因 |
|---|---|
| SSH 连接 | 地址/端口不对、SSH 服务没开；或者主机指纹变了 |
| SSH 登录 | 公钥没加到 `authorized_keys`、用户名不对；密码登录被服务器关闭了 |
| 连上 Hermes gateway | 提示“gateway 没在运行”：在电脑上运行 `hermes gateway`；提示“这个版本的 Hermes 不支持”：Hermes 太旧，需要升级 |
| 读取会话 | gateway 连上了但读不了对话记录，把提示原文发给开发者 |

以前（0.13 及更早）SSH 方式是把 API Server 的 8642 端口转发到手机，所以要开 API Server、填 API Key；现在都不需要了。
已经写进 `.env` 的 `API_SERVER_*` 不影响 SSH 连接，留着也没关系（直连 / HTTPS 还在用的话不要删）。

## 发图片、拍照、发文件

聊天页左下角「+」：相册（一次最多 10 张）、拍照、文件。

| 发什么 | 怎么交给 Hermes | 哪些连接方式能用 |
|---|---|---|
| 图片、照片 | 压缩到长边 2048 后直接发给 Hermes 看；原图也传一份到电脑上（见下面的位置）。模型不能看图时，Hermes 会先用视觉辅助模型描述图片 | 全部（传原图要 SSH） |
| 文件（txt、yaml、代码、PDF、Word、压缩包……照片以外的都是） | 原样传到 Hermes 那台电脑上，消息里只告诉 Hermes 文件在哪，它用自己的工具打开、处理。不会把内容贴进消息，PDF 也不会转成图片 | SSH、直连/HTTPS 打开了「文件互通」、本机 Termux |

文件放在电脑上的哪里：

- **项目里的对话**：项目文件夹下的 `uploads/`（比如项目是 `~/读书计划`，文件就在 `~/读书计划/uploads/`）。
- **其它对话**：连接设置里的「文件上传位置」，默认 `~/hermes-uploads`（`~` 是 SSH 登录用户的主目录）。
- 保留原文件名；同一个文件夹里已经有同名文件时，自动叫 `config (1).yaml`、`config (2).yaml`……不会覆盖。
- **本机 Termux**：存到手机的「下载/Hermes」。Termux 要读那里的文件，需要先在 Termux 里运行一次 `termux-setup-storage` 并允许存储权限。

为什么没有 SSH 就发不了文件：Hermes 的 API 只收文字和图片（官方文档写明不支持上传文件），文件只能经 SSH 传到那台电脑上。
直连、HTTPS 连接没打开「文件互通」时，「+」里的「文件」是灰的，图片照常能发。

### 显示和打开 Hermes 生成的图片、文件（文件互通）

Hermes 画的图、生成的文件都存在它那台机器上（回复里是一行 `MEDIA:/路径`，或者直接写出的文件路径）。
App 每次发消息都会告诉模型“这个客户端能收文件，用 `MEDIA:/绝对路径`”；模型没照做、只写了路径时，App 也会识别出来。
图片直接显示，其它文件变成卡片，点开可以「打开 / 分享 / 保存到手机」。

Hermes 的 API 不提供下载，所以 App 要能经 SSH 读那台机器上的文件：

- **SSH 连接**：自动就能用。
- **本机 Termux / 直连**：在连接设置里打开「文件互通（可选）」，填那台机器的 SSH 账号。
  本机 Termux 填 Termux 自己的 sshd：端口 8022，用户名随便（Termux 不检查），推荐在 App 里生成密钥，
  把「复制命令」得到的那行在 Termux 里执行一次。聊天仍然直接连 Hermes，SSH 只用来传文件。
  打开后就能发文件了：文件经 SFTP 传到上面说的位置。

### 「文件互通」里 SSH 的常见问题

| 提示 | 处理 |
|---|---|
| SSH 登录失败 | 公钥没加进 Termux / 那台机器的 `authorized_keys`，或者用户名、端口不对 |

### 直连

直连要求 Hermes 的 API Server 监听在手机能访问到的地址上。默认只监听 `127.0.0.1`，所以从别的设备直连会失败；
要直连就在那台机器的 `.env` 里设 `API_SERVER_HOST=<它的局域网或 Tailscale IP>`。在同一台手机上用 Termux 时，用「本机 Termux」就够了。

发过的图片会在手机上留一份（按内容哈希命名），以后打开聊天记录还能看到原图；换了手机或清除了 App 数据，旧消息里的图片会显示成占位块。

## 让 Hermes 能向你追问（可选）

Hermes 默认不给 API Server 用“追问”工具，遇到不确定的地方它会自己拿主意。想让它在手机上弹出追问卡片问你，
在 `~/.hermes/config.yaml` 里加上（然后重启 gateway）：

```yaml
platform_toolsets:
  api_server:
    - hermes-api-server
    - clarify
```

## 配置模型提供方

设置 →「模型与提供方」可配置当前连接的 API 密钥、订阅账号、自定义端点及已有本地模型服务。远程修改需 SSH；本机在「本机运行与服务」安装后自动进入该页面。详细步骤与限制见 [模型设置与本机部署](model-settings.md)。

## 切换模型

聊天页顶部点模型名可以给这个对话换模型（之后的每一轮都用它）；“能力 → 模型”里可以设“新对话默认模型”，只影响在手机上新建的对话。
列表里只出现 Hermes 那边已经登录过的 Provider。想加 Provider，在那台机器上运行 `hermes model` 或 `hermes login`。

## 定时任务

“任务”页能新建、编辑、暂停、立即运行和删除 Hermes 的定时任务。每次运行的结果是一个新对话，出现在聊天列表里（来源“定时任务”）；
在 App 里点“立即运行”后，Hermes 一般一分钟内开始执行，跑完会发通知。要让 Hermes 按时执行，gateway 要一直在运行
（Termux 上记得 `termux-wake-lock`）。如果“任务”页显示“这台 Hermes 不支持定时任务”，说明它的版本还没有 `/api/jobs` 接口。

## 技能、工具集和插话

- “能力 → 技能”列出 Hermes 装好的技能，点开可以在新对话里用它；任何对话里输入 `/技能名 要做的事` 也一样。
  有的 Hermes 版本（v0.22 canary）读技能列表的接口本身有问题，这时如果连接配了 SSH，App 会直接读 `~/.hermes/skills` 目录。
- “能力 → 工具集”显示 Hermes 回复时能用哪些工具。配了 SSH 的连接可以直接开关（App 在服务器上执行 `hermes tools enable/disable`），
  否则在那台机器上运行 `hermes tools` 修改。SSH 登录后要能找到 `hermes` 命令。
- Hermes 正在回复时，你可以接着打字发送，这叫“插话”：它不会被打断，会在下一步看到你补充的话。想让它停下，输入框空着时点停止按钮。

## 管理 Hermes（能力 → 更多）

- **记忆**：Hermes 记住的关于你的事（USER.md）和它自己的笔记（MEMORY.md），可以改、删、加，显示已用字数和上限。
- **MCP 服务器**：添加（网址或本机命令）、测试连接、启用/停用、删除。改的是 config.yaml，Hermes 会自动重连。
- **Gateway**：运行状态、接入的平台（Telegram 等）是否连着、今天的请求和 Token 用量；配了 SSH 还能看最近的日志。
- **配置文件**：直接编辑 config.yaml。保存前会让 Hermes 先检查格式，有错不会覆盖；原文件备份为 `config.yaml.mobile-backup`。
  API Key 等密钥在 `.env` 里，App 不显示也不改。

除了 Gateway 状态，其它都要连接配了 SSH。本机 Termux：在 Termux 里 `pkg install openssh`、`passwd` 设密码、运行 `sshd`（端口 8022），
然后在连接设置里填 SSH 用户名（`whoami` 的结果）和密码。SSH 登录后要能直接运行 `hermes` 命令。

## 会话分组

如果你在 Hermes 桌面版里用了项目（比如“downloads”），聊天列表上方会出现分组标签，可以按分组查看；
看“全部分组”时，每个会话标题旁边会标出它属于哪个分组。分组要经 SSH 读取（服务器上要有 python3），
读到之后会存在手机上，下次打开直接显示。

有 SSH 时还可以：
- **新建项目**：点分组那一行最前面的“新建项目”，起个名字，再在电脑上一层层点到要用的文件夹（也可以在里面“新建文件夹”）。
  对话框下面写着项目会存进哪个 Hermes 目录：电脑版 Hermes 连的是同一台机器、同一个 Profile，才看得到手机建的项目。
- **改名、删除项目**：点选一个项目标签，下面会出现它的文件夹和“重命名”“删除”。删除只删项目本身（和电脑版一样），对话和文件夹都还在。
- **把对话移进项目**：长按对话 →“移到项目…”，选项目，或者“移出项目”。和桌面版拖动会话的效果一样。
- **在项目里开新对话**：先点选上面的项目标签，再点右下角的新对话按钮。之后 Hermes 会被告知在项目文件夹里干活。

## 归档

在聊天列表里左滑一个对话，点“归档”，它就从列表里收起来（Hermes 桌面版里也是归档状态），可以马上点“撤销”。
归档的对话在“已归档”筛选里，左滑可以取消归档或删除。

## Bot

Hermes 的每个 Profile 就是一个 bot（电脑版 Hermes 里叫 Bot）：有自己的名字、头像、性格（SOUL.md）、模型、对话、记忆和定时任务。
底栏的「Bot」页列出那台电脑上所有的 bot（需要这个连接配了 SSH）。

- **和它聊**：点一个 bot，App 换成和它聊，并打开它的固定对话「Bot Chat」（电脑版也是这个对话）。聊天列表顶部会显示正在用哪个 bot，列表里只有这个 bot 的对话。
- **开通手机访问**：第一次点某个 bot 时，App 会先说明要改什么，你点「开通」才做：给这个 bot 生成它自己的 `API_SERVER_KEY`（写进它的 `.env`，已有就用原来的），
  需要时打开 `gateway.multiplex_profiles` 并重启一次 gateway（只有第一次需要；重启时正在进行的回复会中断）。
- **新建**：Bot 页右下角的「+」。填名字（中文也行，会自动生成一个英文 ID，比如「小助手」→ `u5c0f-u52a9-u624b`）、它负责什么、性格（可以不填，自动写一份），选颜色或照片当头像。
  新 bot 和电脑版新建的一样：从默认 bot 复制模型、API Key 和技能，不复制 Telegram 等聊天平台的 bot token。
- **编辑 / 删除**：长按 bot 或点右边的「⋮」。可以改名字、头像、描述、性格和模型。删除会从电脑上删掉这个 bot 的所有对话、记忆和技能，不能恢复；默认 bot 不能删。

### 群聊

Bot 页上方是群聊：拉 2～6 个 bot 进一个群，你发一条，它们一起讨论（和电脑版的群聊是同一个东西，两边都能看到、都能发）。

- 不 @ 谁时每个 bot 都会答；`@码农`（输入框左边的 @ 按钮可以选）就只让它答，`@all` 是所有人。bot 之间互相 @ 会再接着聊，最多 3 轮 / 10 条，然后停下等你。
- bot 没话可说时会自己“跳过”，不会硬凑一条。
- 有 bot 要执行需要批准的操作时，群里会出现一张卡片让你允许或拒绝；正在讨论时输入框右边的按钮是「停止」。
- 群聊是在电脑上的 Hermes gateway 里跑的，手机经 SSH 连过去收发，不需要给每个 bot 开通手机访问；但 gateway 要能同时服务这几个 bot（`gateway.multiplex_profiles`，开通任意一个 bot 的手机访问时会打开）。
- 右上角菜单可以改群名、解散群聊（只删群聊记录，bot 本身不受影响）。

## Bot 屏幕（看 bot 的桌面、接管）

Hermes 跑在 Linux 主机（服务器、云主机）上时，可以给每个 bot 开一块虚拟桌面，bot 的 `computer_use` 和浏览器在上面操作，
电脑版 Hermes 里叫 Screen。手机上在「能力 → 更多 → Bot 屏幕」，或者聊天页右上角菜单里打开（需要这个连接配了 SSH）。

- 默认只看。点「接管」后，你的点按和打字才会发到屏幕上，这期间 bot 的屏幕工具会被拒绝（和电脑版一样，电脑版也会看到有人接管）；用完点「交还」。离开这个页面也会自动交还。
- 操作：点一下是左键，两指点一下是右键，单指拖动是拖拽，两指上下滑是滚轮。右上角的放大镜切换“适应屏幕 / 原始大小”（原始大小时单指拖动画面）。手机横过来看更清楚。
- 接管时下面有一排键（Ctrl、Alt、Esc、Tab、方向键、回车……）和一个输入框：在输入框里打的字（中文也行）会打到屏幕上；「粘贴」把手机剪贴板里的内容打上去（比如密码）。
- 屏幕没开时可以从手机上「启动屏幕」；主机没装需要的软件时，页面上会给出要在主机上运行的安装命令。
- 画面经 SSH 直接接到 Hermes 的屏幕，不开新端口。查看器是打包进 App 的 noVNC（和电脑版同一个版本）。

## 后台和通知

等 Hermes 回复时，App 会在通知栏显示“Hermes 正在回复…”，这样切到后台、锁屏也不会断。
回复到了、或者需要你批准时会发通知。第一次打开 App 时请允许通知。
如果手机厂商的省电策略比较激进，建议把本 App 设为“不限制后台”。

## 多个 Profile

一般直接用「Bot」页切换就行（见上面的 Bot）。也可以给某个 Profile 单独建一个连接：在连接里填 Profile 名字，并在那台机器的 `config.yaml` 里开启 `gateway.multiplex_profiles`。
每个 Profile 要在自己的 `~/.hermes/profiles/<名字>/.env` 里设置单独的 `API_SERVER_KEY`，App 里填的也是这个 Profile 的 Key。
想同时用几个 Profile，就为每个 Profile 建一个连接，在聊天列表顶部切换。
