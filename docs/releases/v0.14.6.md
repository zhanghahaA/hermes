## 0.14.5 以来的新变化

**修好：在手机上装的 Hermes（Termux），模型设置选「自定义端点」读不出模型。** 「读取可选模型列表」以前没有把你填的地址和密钥交给 Hermes，只在已保存的配置里找，新填的端点永远是空列表。现在：

- 用你正在填的地址、密钥和接口格式实时读取端点的模型清单（和电脑版设置页「测试」按钮用的是 Hermes 里同一个功能），读取不会改配置；
- 实际能用的是补上 `/v1` 的地址时，地址框自动改过去；模型名空着时先填第一个，也可以「从模型列表选择」；
- 读不到时说清楚原因：连不上、密钥被拒、端点返回的错误码、没有模型清单、接口格式不对。说明就显示在按钮下面；
- 保存时把读到的模型清单一起存下，聊天页切换模型时也能选到；
- 密钥留空时，只有地址和之前保存的一样才沿用已保存的密钥，不会把旧密钥发到新地址。

**局域网里的模型服务可以用 http 地址了。** 以前自定义端点只接受 https 和本机地址，电脑上跑的 Ollama / LM Studio 等（如 `http://192.168.1.10:11434/v1`）填不进去。现在本机、局域网私有地址（10.x、172.16–31.x、192.168.x）、Tailscale（100.64–127.x）和 `.local` 可以用 http，页面上会提示密钥在局域网里明文传输；公网地址仍然要 https。

注意：Hermes 装在手机上时，`127.0.0.1` 指的是手机自己。模型跑在电脑上要填电脑的局域网地址，并让电脑上的模型服务允许局域网访问。

## New since 0.14.5

**Fixed: on Hermes installed on the phone (Termux), “Custom endpoint” in model settings could not read any models.** “Load available models” did not pass the address and key you typed to Hermes; it only looked at the saved configuration, so a newly entered endpoint always came back empty. Now:

- The model list is read live from the endpoint with the address, key and API format you typed (the same Hermes function as the desktop settings' Test button). Reading does not change the configuration.
- If the working address is the one with `/v1` added, the address field is updated to it; an empty model name is filled with the first model, and you can pick another from the list.
- Failures explain why: unreachable, key rejected, the HTTP status returned, no model list, or wrong API format. The explanation appears right under the button.
- Saving keeps the discovered model list, so the chat model picker shows these models too.
- With the key left blank, the saved key is reused only for the same address it was saved with, never sent to a new address.

**Model servers on your local network can use http.** Custom endpoints used to accept only https and loopback, so Ollama / LM Studio running on a computer (e.g. `http://192.168.1.10:11434/v1`) was rejected. Loopback, private LAN ranges (10.x, 172.16–31.x, 192.168.x), Tailscale (100.64–127.x) and `.local` now accept http, with a note that the key travels unencrypted on the LAN. Public addresses still require https.

Note: when Hermes runs on the phone, `127.0.0.1` is the phone itself. For a model running on a computer, enter the computer's LAN address and allow LAN access in the model server.
