## 新旧流程

旧流程每次重写 `.env`、按公钥整行去重、后台请求重启后立即输出敏感回执。

现在先检查 Hermes 命令、地址和当前用户的 SSH 服务；验证配置后只更新有差异的 API_SERVER_* 项。已有 API_SERVER_KEY 不管是否有效都不被替换：无效时停止，缺失时才首次配置。模型供应商 Key 不参与配对逻辑。冲突的重复 API 配置要求人工确认，不擅自选一个值。

同一用户的授权文件使用锁，整个 Profile 的配对也使用锁。写入保留原子替换、首次私有备份、权限及符号链接检查。配置／授权写入失败时恢复本次修改前的内容，不用陈旧的首次备份覆盖新数据；进程被强制终止可能留下部分已完成步骤，再次执行会按现状继续。服务启动失败时保留有效配置和授权，方便重试，不清理用户数据。

配置无变化且 API 身份与认证通过时不重启。否则调用当前 HERMES_HOME 下的 `hermes gateway restart`，等待健康与 `/v1/models` Bearer 认证结果，最多 90 秒。发现认证拒绝或端口不是可验证的 Hermes 时明确停止。CLI 输出不写入配对日志，不把启动请求当成功。手机仍通过已有 `testConnection` 验证主机指纹、SSH 登录、转发通道、HTTP、认证及会话能力，最终通过才保存并连接。

服务关系核对依据：上游 `hermes_cli/gateway.py`，以及仓库 `docs/protocol.md`。API Server 是 Gateway 的组成部分；官方 restart 负责服务管理器和无系统服务时的运行回退。没有添加 `--all`、`--force`，不越过多 Profile、外部监督器和活跃会话保护。上游若拒绝重启，报告失败，不擅自停止宿主实例。

## 短命令与隐私

首次命令仍是自包含命令，使用标准库 zlib 压缩助手。助手保存到 `~/.cache/hermes-mobile-pair/<SHA256>.py`，不依赖第三方下载地址或额外 Python 包。用户执行过首次命令后，可点「已执行过？复制简短重试命令」；该命令只携带参数与校验加载器，不再携带整个程序，使用前验证助手内容摘要。缓存缺失或被修改时停止，重新执行完整命令即可修复。

这不是上游原生 `hermes mobile pair` 子命令，不冒充其已实现。首次部署和短重试都是复制一次、执行一次。

SSH 命令不包含 API Key；结果存于 0600 的 Profile 私有回执，由已认证的 SSH 读取。默认终端不回显回执或 API Key。旧协议的回执格式继续兼容。Python 助手仅在显式传入 `--show-result` 时允许导出旧版敏感回执；安卓新流程不添加此参数。

**直连兼容边界：**现有直连协议仍将手机首次配置的 API Key 编入敏感安装命令，Base64 不等于加密，不能将它当公开配对码传播。复制仍标记为敏感；不要保存或分享完整命令。服务器已有不同 Key 时不会轮换，用户需在手机填写已有 API Server Key（以及保留的端口）。无 SSH 的直连尚未实现不携带密钥的安全交换协议。因此本版不能宣称所有连接类型都已实现“公开短配对码无密钥”。

## SSH 和 Profile

公钥身份按算法与实际公钥数据比较，不按注释比较，也不会把 `command="..."` 内的文本当作公钥。配对助手验证公钥 wire 数据。已有受限公钥保持原限制，不额外添加无限制副本。新授权禁用 agent 转发、X11 转发和 PTY；保留 App 所需的 TCP 隧道、非交互命令及文件操作。由于 App 要管理模型、工具、文件与屏幕，不能同时强制单个只读命令；授权仍拥有该系统用户的远程命令能力。

「复制本手机授权撤销命令」在服务器执行后只删除匹配公钥的行，保留其他授权。共用同一私钥的设备会同时失去新连接权限；现有 SSH 会话不会被该文件操作强制断开。删除 App 的连接记录不等于撤销服务器授权。

Profile 路径按默认根或 `profiles/<name>` 规范化，避免已有 HERMES_HOME 指向 Profile 时重复拼接；命名 Profile 必须已存在。默认／命名 Profile 各自配置与回执隔离，HTTP 使用对应 `/p/<profile>`。共享 Gateway 的重启范围由 Hermes 自身保护决定；本版不自动变更共享 Gateway 的布局或启用多路复用。

## 兼容与迁移

无需迁移已有配置，不新增自动轮换密钥功能。旧客户端保存的连接和旧回执解析继续兼容；旧客户端此前复制的旧脚本仍然具有旧行为，应在新版重新复制命令。新助手缓存可重新生成，不包含用户配置。原有短／空 API Key、冲突配置和错误 Profile 需明确修正，不能通过静默换 Key 绕过。
